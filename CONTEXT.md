# Cat Breed Classifier

This context covers the browser-based experience for classifying cat breeds and explaining the result to the person viewing it.

## Language

**Built-in model**:
A cat-breed classification model provided by the application for direct use, rather than uploaded by the user.
_Avoid_: Default model, system model

**Occlusion explanation**:
A visual explanation for one Prediction that highlights image regions whose removal changes that Prediction's breed score. It describes the selected Built-in model only, not an ensemble of models.
_Avoid_: Grad-CAM, Score-CAM, confidence map, proof of breed

**Occlusion sensitivity**:
The analysis method that measures how much a Prediction's breed score changes when different image regions are removed.
_Avoid_: Grad-CAM, Score-CAM, model confidence

**Prediction**:
The breed label and confidence produced by the Built-in model selected by the person viewing the application for an uploaded image.
_Avoid_: Diagnosis, guarantee

**Explanation quality**:
The degree to which a natural-language explanation is factually supported by the input image, aligned with the available model evidence, free from unsupported claims, and consistent across repeated explanations.
_Avoid_: Classification accuracy, model confidence

**Hallucination**:
An incorrect or materially deviated breed described by the LLM when compared with the dataset reference label of the test image.
_Avoid_: Any prediction error, low confidence, unsupported visual detail unless it is separately annotated

**Explanation consistency**:
The degree to which repeated structured breed outputs for the same image and condition preserve the same conclusion.
_Avoid_: Prediction stability, classification accuracy

**LLM-only explanation**:
A natural-language explanation generated from the input image without the CNN prediction or occlusion evidence supplied to the LLM.

**CNN-grounded explanation**:
A natural-language explanation generated by an LLM that receives the CNN prediction as additional evidence, without receiving occlusion evidence.

**Occlusion-grounded explanation**:
A natural-language explanation generated by an LLM that receives the CNN prediction and an occlusion-sensitivity visualization indicating which image regions affected the predicted class score.

**CNN evidence**:
The selected CNN's predicted breed label, model score, and, when enabled, occlusion-sensitivity heatmap supplied to the LLM as explanatory evidence. CNN evidence is not the reference label; the test-set dataset label remains the reference for breed-level evaluation.

**Experimental condition**:
One of three controlled explanation inputs: LLM-only, CNN-grounded, or occlusion-grounded. The conditions use the same LLM and generation protocol while incrementally adding CNN prediction evidence and occlusion evidence.

**Structured breed field**:
The canonical breed label explicitly returned by the LLM for quantitative evaluation, kept separate from the free-form natural-language explanation.

**Occlusion evidence package**:
The original image, the same image with the occlusion-sensitivity heatmap overlaid, and the CNN prediction score supplied to the LLM for an occlusion-grounded explanation.

**Natural-language explanation**:
The user-facing explanation remains free-form and conversational. Quantitative evaluation may identify the breed claim from the generated text after generation without imposing a structured response format on the user-facing output.

**Breed-level explanation reliability**:
The primary evaluation scope for the research study: whether the structured breed field returned with an explanation matches the dataset reference label. It is measured primarily with Macro-F1 and breed-level error rate, and does not establish that every free-form visual attribute is faithful.

**Primary outcome**:
The pre-specified main study outcomes are structured breed correctness summarized by Macro-F1 and breed-level error rate.

**Secondary outcome**:
Additional study outcomes that support interpretation but do not replace the primary outcomes: breed-level output consistency across repeated generations and invalid-response rate.

**Breed-level output consistency**:
The secondary repeated-generation outcome used in the research study: the proportion of two responses for an image-condition pair that match the most frequent valid structured breed output. It measures conclusion consistency only, not consistency or faithfulness of the free-form explanation.
